# Tarea en equipo: GitHub

## Objetivo
Preparar el repositorio para una practica colaborativa en grupo, diferenciando claramente los entornos de desarrollo y produccion.

## Estructura de ramas
- `main`: rama principal limpia (sin archivos de proyecto).
- `dev`: entorno de desarrollo.
- `prod`: entorno de produccion.

## Contenido de la rama prod
En esta rama se mantiene contenido orientado a produccion:
- `dist/index.html`
- `src/app.js`
- `version.txt`
- `prueba.txt`

## PASOS realizados
1. Se creo el repositorio en GitHub.
2. Se configuraron ramas para trabajo colaborativo.
3. Se cargo contenido para `dev`.
4. Se cargo contenido diferente para `prod`.
5. Se documento el proceso en este `README.md`.
