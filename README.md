# Tarea en equipo: GitHub

## Objetivo
Preparar el repositorio para una practica colaborativa en grupo, con ramas separadas para desarrollo y produccion, y con una rama principal limpia.

## Estructura de ramas
- `main`: rama principal limpia (sin archivos de proyecto).
- `dev`: entorno de desarrollo.
- `prod`: entorno de produccion.

## Contenido de la rama dev
En esta rama se mantiene contenido orientado al desarrollo:
- `src/app.js`
- `version.txt`
- `prueba.txt`

## PASOS realizados
1. Se creo el repositorio en GitHub.
2. Se crearon y organizaron las ramas de trabajo.
3. Se cargo contenido para `dev`.
4. Se cargo contenido distinto para `prod`.
5. Se documento el proceso en este `README.md`.

## Nota para la practica de conflictos
Este repositorio queda preparado para que varios companeros trabajen en paralelo y practiquen manejo de conflictos (`merge conflicts`).
